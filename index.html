☁️ 首次使用：配置云端

数据只存云端，换手机不丢。配一次就行。

第1步：建存储
打开 gist.github.com 登录 → 点「+」→ New gist → 文件名 ledger.json → 内容填 {"flows":[],"members":[],"shops":[],"payments":[]} → 选 Secret → 创建
第2步：拿 Gist ID
创建后看地址栏，gist.github.com/你/ 后面那串就是
第3步：建 Token
打开 github.com/settings/tokens?type=beta → Generate new token → 命名 → Repository access 选那个 gist → Permissions 里 Contents 选 Read and Write → 生成后复制 ghp_ 开头字符串

配好后数据自动存云端，本地不丢
